## Task Guidelines

### Adding a Task

1. Add a row to the **Active Tasks** table.
2. Set the status to ⬜ Pending.
3. When starting work, update the status to 🔄 In Progress.
4. Log detailed changes in the corresponding `../logs/{module}_changes.md` file.

### Completing a Task

1. Run linting and tests.
2. Update the status to ✅ Completed.
3. Move the row from **Active Tasks** to **Completed Tasks**.
4. Ensure the change log is updated.
